# 园区政府管理平台演示脚本

面向现场讲解。全程用浏览器里的样例，不连后端。建议用桌面宽度打开。样例园区是滨江云栖、临港智造、光谷生命。电话、统一社会信用代码和金额都是虚构的。

## 地址

线上入口（仓库 Settings → Pages 必须选 Deploy from a branch，Branch 为 `dist`，Folder 为 `/ (root)`，否则下面三个地址会 404）：

| 入口 | 地址 |
| --- | --- |
| 门户 | https://dxhcode.github.io/park-gov/ |
| 管理端 | https://dxhcode.github.io/park-gov/admin/ |
| 态势大屏 | https://dxhcode.github.io/park-gov/screen/ |

管理端和大屏是两个入口。门户页两张卡片分别进入。管理端未登录会停在登录页；大屏不登录也能看。

本地开发时端口不同，页面里的「大屏 / 返回管理端」会在 5173 和 5174 之间跳：

```bash
pnpm install
pnpm dev:admin     # http://localhost:5173/park-gov/admin/
pnpm dev:screen    # http://localhost:5174/park-gov/screen/
```

按线上路径预览整站：

```bash
pnpm pages:preview
# http://127.0.0.1:4173/park-gov/
```

## 建议走查（约 8 分钟）

下面的路径是管理端路由。浏览器里要加上 base：线上是 `/park-gov/admin`，本地是 `http://localhost:5173/park-gov/admin`。

### 1. 从门户进登录

1. 打开 https://dxhcode.github.io/park-gov/ 。
2. 观众应看到深色门户、金色印章，以及「管理端工作台」「监管态势大屏」两张卡片。
3. 点「管理端工作台」，进入 https://dxhcode.github.io/park-gov/admin/login 。

### 2. 登录并落到工作台

1. 点左侧「周岚」。用户名变成 `zhoulan`，密码填入 `Park@2026`。
2. 点「进入工作台」。
3. 观众应看到墨色顶栏（周岚 · 经济发展局 · 企业监管专员）、左侧菜单，以及工作台的四张指标和事项表。
4. 路由：`/workbench`。快捷入口按演示顺序排列：企业名录、用房、闲置、风险画像、用地、园区考核、投诉举报、数据报送，末尾两个渐变按钮是大屏。

### 3. 企业空间监管主线

1. 点快捷入口「企业名录」，或侧栏「企业监管 → 企业名录」。路由 `/enterprise/directory`。
2. 园区筛「滨江云栖」。表里应留下星澜智造、青禾生物、峦数信息、澄江半导体、北麓云测。
3. 点「星澜智造科技有限公司」。路由 `/enterprise/directory/ent-xinglan`。
4. 观众应看到信用代码 `91330108MOCK00001X`、承租用房、风险画像「危化品暂存台账缺页」、同楼闲置。
5. 点风险信号进入画像详情 `/enterprise/risk/risk-xinglan`。等级是高风险，承办人陈启明。详情里的企业名称可以点回档案。
6. 回到企业详情，点承租用房「A1-801」。路由 `/space/building/room-a1-801`。
7. 用房详情底部是「同楼闲置」。点一条闲置，例如 A1 的闲置记录，再从「同楼用房」点回 A1-801。这条来回就是企业、用房、闲置三条台账。

侧栏同一主线还可以单独打开：

| 页面 | 路由 | 观众应看到 |
| --- | --- | --- |
| 用房 | `/space/building` | 载体、承租企业、空置待租。右上「空间态势大屏」 |
| 闲置 | `/space/idle` | 待盘活、洽谈中、已盘活。闲置满一年会有红标 |
| 用地 | `/space/land` | 规划用途和实际利用。待供应地块在云栖东侧、光谷东区 |

### 4. 其余子系统各看一眼

每页都是列表、详情、新建。演示时点开一条详情即可，不必真的保存。若改过数据，顶栏姓名菜单里有「恢复样例数据」。

| 页面 | 路由 | 点哪里 | 观众应看到 |
| --- | --- | --- | --- |
| 风险画像 | `/enterprise/risk` | 星澜或远能动力 | 高风险、待核查，企业名可进档案 |
| 园区考核 | `/assessment` | 已归档的高分项，或记 0 分的短板 | 进度和得分。未开始的得分是 0 |
| 投诉举报 | `/complaint` | 临港异味或工资件 | 渠道、承办人、办结时限 |
| 政策管理 | `/policy` | 任意一条已发布 | 文号和摘要。没有附件正文 |
| 数据报送 | `/submission` | 一条已报送 | 去向和回执号。不会真的上报 |
| 统计分析 | `/analytics` | 快捷入口，不要找图表 | 只有文字摘要。「可导出」是状态，不下载文件 |
| 系统设置 | `/settings` | 一条角色或字典 | 说明文字。不会拦截菜单 |

### 5. 进态势大屏

从管理端进大屏时，地址会带 `from`，大屏右上角和底栏按来源返回。

1. 在工作台点渐变按钮「监管总览大屏」。线上打开 https://dxhcode.github.io/park-gov/screen/overview?from=%2Fworkbench 。
2. 观众应看到深色玻璃舱、四枚滚动数字、金色滚动字幕、三园示意图、月度产值折线、告警流。
3. 点地图上的滨江云栖、临港智造、光谷生命。右侧摘要换成该园的电话和产值。
4. 点「重点企业」里的公司名，回到管理端对应档案（未登录会先经过登录页，再回到该企业）。
5. 顶栏六个场景依次点：空间态势、企业风险、考核看板、投诉热力、告警中心。每个场景都有指标条、滚动字幕和本场景的图。
6. 空间态势点园区后，右侧只留该园斑块。企业风险页点公司名同样回到档案。
7. 点右上角「返回工作台」（若从别的台账进来，文案会变成「返回企业名录」等）。

也可以不登录，直接打开 https://dxhcode.github.io/park-gov/screen/ 。默认进监管总览。这时返回按钮去工作台，未登录会被送回登录页。

| 场景 | 路由 | 观众应看到 |
| --- | --- | --- |
| 监管总览 | `/overview` | 三园底图、产值折线、告警流、重点企业 |
| 空间态势 | `/space` | 用地 / 用房 / 闲置斑块，入住率和未盘活面积 |
| 企业风险 | `/enterprise-risk` | 风险环、行业条、处置闭环、企业分数 |
| 考核看板 | `/assessment` | 已出分条形、四类结构、记 0 分的短板 |
| 投诉热力 | `/complaint-heat` | 园区热力、类型环、超时件 |
| 告警中心 | `/alerts` | 循环告警、等级环、承办人去向。鼠标停在告警列表上会暂停滚动 |

大屏路由的完整前缀是 `/park-gov/screen`。

### 6. 收尾

1. 回到管理端顶栏，点姓名，选「恢复样例数据」。观众应看到提示「已恢复初始样例数据」。企业、用房、闲置和其余台账一起回到初始样例。
2. 再点「退出登录」，回到登录页。未登录直接打开 `/workbench` 也会回到登录页。

## 讲解时可以强调的三句话

- 管理端是办事台账，大屏是同一批样例的态势舱，两边用渐变按钮和右上角返回串起来。
- 企业名录、用房、闲置可以沿着档案里的链接互相点通，风险画像挂在企业上。
- 所有改动只在这台浏览器里。刷新还在，换浏览器或清站点数据就没了。大屏数字是单独准备的快照，改台账不会改大屏。
