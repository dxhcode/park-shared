# 园区运营平台

演示步骤见 [DEMO.md](./DEMO.md)，阶段缺口见 [GAPS.md](./GAPS.md)。

智慧园区前端原型。pnpm monorepo 内含两个 Vue 应用：

- `apps/admin-app`：管理控制台，深色侧栏与中文业务菜单
- `apps/screen-app`：态势大屏，全屏科技风场景壳
- `packages/shared`：两端共用的站点名称

管理端已接通演示登录。侧栏每个菜单都能打开：报修工单、物业缴费，以及园区、企业、访客、表计、点位、公告和系统台账。数据写在浏览器本地。态势大屏是三园驾驶舱，含示意地图、图表和滚动指标。

## 本地运行

```bash
pnpm install
pnpm dev
```

- 管理端：http://localhost:5173/
- 态势大屏：http://localhost:5174/

也可以单独启动：`pnpm --filter @park/admin-app dev`、`pnpm --filter @park/screen-app dev`。

## 管理端台账

除报修和缴费外，其余菜单使用同一套列表、详情、新建和编辑。筛选没有结果时，会出现清空筛选和新建。示例数据按临港智慧园区编写，可在列表里恢复。

- 工作台汇总未闭环工单、未结清账单、待审核访客、置顶公告、即将到期合同和异常表计。
- 园区信息、楼宇管理、空间房间、入驻企业、合同管理、访客通行、能源表计、安防点位、通知公告、用户、角色、菜单均可增删改。
- 用户、角色、菜单只是本机台账，不会改登录账号、权限或左侧真实导航。
- 能源页是表计读数，安防页是点位状态，都不播放曲线或视频。曲线和示意地图在态势大屏。
- 报修、缴费和各台账顶部的数字可以点击，用来筛选当前列表。

## 态势大屏

大屏默认可直接浏览。顶栏可在六个场景之间切换，布局各不相同：

- 综合态势：示意地图、产业结构、出租率、收费折算和通行负荷曲线
- 物业运行：班组进度、设施在线率和遗留事项
- 工单态势：状态环、类别条和滚动工单墙
- 能耗监测：水电曲线、楼宇用电和表计
- 通行安防：人车分时、闸口、点位和访客
- 告警中心：等级、来源和滚动告警墙

园区可切换为滨江云栖科创园、临港智造产业园、光谷生命科学园。电话、金额和曲线都是虚构演示数据。底部有滚动指标条。

## 演示跳转

管理端顶栏、工作台，以及报修、缴费、园区、企业、公告、能源、安防、访客都可以打开大屏。地址带上 `park` 和 `from`。大屏右上角「返回管理端」按 `from` 回到原来的后台页面，包括园区、企业和系统设置；场景切换会保留这两个参数。本地开发时管理端是 `5173`，大屏是 `5174`，两边会话不共享。GitHub Pages 上则走 `/park-campus/admin/` 与 `/park-campus/screen/`，同域会话可以共享。刷新深层地址时会保留查询参数。

## 报修与缴费

- 报修工单：`/workorders` 列表可按状态、优先级、类别和关键字筛选，行内进入详情，支持新建、编辑、受理派单、提交验收、完工和关闭。
- 物业缴费：`/billing` 列表可筛选，详情可看收款记录，支持开立账单和登记收款。未缴清且已过到期日的账单显示为已逾期。
- 示例数据以临港智慧园区的楼宇和企业编写。改动保存在本机，页面上可以恢复示例。

## 构建与 GitHub Pages

生产构建的 Vite `base` 分别为 `/park-campus/admin/` 与 `/park-campus/screen/`。本地开发仍使用 `/`。

```bash
pnpm pages:build
```

产物目录：

- `dist/index.html`：入口页，链到管理端和大屏
- `dist/admin/`：管理端
- `dist/screen/`：大屏
- `dist/404.html`：深层路由刷新时回到对应应用

`dist` 分支根目录已经是可发布的静态包。开启 Pages 需要仓库管理员权限；当前自动化令牌调用 Pages 接口会返回 403，因此要在网页上打开一次：

1. 打开仓库 Settings → Pages：https://github.com/dxhcode/park-campus/settings/pages
2. Build and deployment 选择 **Deploy from a branch**
3. Branch 选择 `dist`，文件夹选择 `/ (root)`，保存

保存后的地址：

- https://dxhcode.github.io/park-campus/
- https://dxhcode.github.io/park-campus/admin/
- https://dxhcode.github.io/park-campus/screen/

站点从已有的 `dist` 分支构建。若保存后短时间仍是 404，等 GitHub 完成第一次构建即可。
