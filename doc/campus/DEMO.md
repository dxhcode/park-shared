# 园区运营平台演示脚本

面向现场讲解的点击顺序。数据都在浏览器里，没有后端。管理端示例台账是临港智慧园区；态势大屏可以换到滨江云栖、临港智造、光谷生命科学，三园数字互不相通。

建议账号：点登录页上的「林知夏」，或手动输入 `admin` / `park2026`。另外两个名片是周启明（物业主管）、陈予安（收费专员），权限相同，只是顶栏姓名和职务不同。

## 地址

入口页会分到管理端和大屏。管理端未登录时进入登录页，登录后默认到工作台。大屏打开后默认是综合态势。

| 场景 | 本地 | GitHub Pages |
| --- | --- | --- |
| 入口 | 无单页入口，两个端口分开开 | https://dxhcode.github.io/park-campus/ |
| 管理端 | http://localhost:5173/ | https://dxhcode.github.io/park-campus/admin/ |
| 登录 | http://localhost:5173/login | https://dxhcode.github.io/park-campus/admin/login |
| 工作台 | http://localhost:5173/dashboard | https://dxhcode.github.io/park-campus/admin/dashboard |
| 报修 | http://localhost:5173/workorders | https://dxhcode.github.io/park-campus/admin/workorders |
| 缴费 | http://localhost:5173/billing | https://dxhcode.github.io/park-campus/admin/billing |
| 大屏 | http://localhost:5174/overview | https://dxhcode.github.io/park-campus/screen/overview |

本地先在仓库根目录执行 `pnpm install` 和 `pnpm dev`。管理端是 5173，大屏是 5174。Pages 要等仓库 Settings → Pages 使用分支 `dist`、目录 `/ (root)` 之后才打得开；保存后若仍是 404，等 GitHub 第一次构建完成。

如果观众中途改乱了数据，各列表右上角都有「恢复示例」。

## 1. 入口和登录

Pages 上先打开入口页。观众会看到两张卡片：管理控制台、态势大屏。页内有一句建议顺序。

点「进入管理端」。未登录会停在登录页：深色网格背景，右侧白卡片。点「林知夏」那张名片，不必再填密码。

观众应看到：成功提示「欢迎回来，林知夏」，进入工作台。顶栏左侧是「临港智慧园区 · 驾驶舱 临港」，右侧金色胶囊是「态势大屏」，头像是林知夏、园区管理员。

登录页上的「先看态势大屏」可以跳过登录。本地会打开 5174，Pages 会打开 `/park-campus/screen/overview`。这条路放在最后讲更顺。

## 2. 工作台

地址：`/dashboard`。

先看四张数字：未闭环工单、待收账单、待审核访客、在园企业。点任意一张会进对应列表。

中间是态势跳转。点「光谷」，再点「综合态势」。

观众应看到：大屏标题变成光谷生命科学园，顶栏「云栖 / 临港 / 光谷」里光谷高亮，地图、图表和底部滚动指标都换成光谷的虚构数。金色条写着「演示跳转 · 来自工作台」。

点右上角「返回管理端」，回到工作台，驾驶舱仍记着光谷。

先不要在这里讲完六个场景，回到主线。

## 3. 报修工单

侧栏点「报修工单」，或打开 `/workorders`。

点指标「待受理」。列表应只剩待受理，其中有「星河楼 12 层东侧公共照明跳闸」，单号 `BX-202610-1062`。

点这一行进详情。点「受理并派单」，处理人保持默认班组，确认。

观众应看到：状态从待受理变成处理中，右侧轨迹多一条「受理并派单」，处理人被填上。

继续点「提交验收」，再点「确认完工」。状态变为已完工，主按钮变成「关闭工单」。可以关掉，也可以留着。

回到列表，点「紧急未闭环」。观众应看到紧急且还没完工或关闭的工单，例如海纳楼客梯异响（若它仍是处理中）。再点一次同一指标，筛选取消。

右上角「工单大屏 · 光谷」（园区名随驾驶舱变化）会打开 `/workorders` 场景，并带上 `from` 和 `park`。

## 4. 物业缴费

侧栏「物业缴费」，地址 `/billing`。

点「逾期笔数」。列表应出现已过到期日且未缴清的账单，行底有淡红色。点「星澜智造（上海）有限公司」的 9 月物业费，单号 `JF-202609-2201`。

详情里未收金额是红的，收款记录为空。点「登记收款」，金额填一部分（不要超过未收），方式任选，提交。

观众应看到：回到详情后出现一条收款，未收变小，状态变成「部分缴纳」。再登一笔把未收结清，状态变为「已缴清」，「登记收款」消失。

点「收费态势」进入综合态势，能看到出租率和收费折算。点「返回管理端」应回到刚才的账单详情，而不是工作台。

## 5. 子系统抽两页

不必逐个菜单点完。抽访客和能源，说明其余台账是同一套列表。

**访客通行** `/visitors`。点指标「待审核」，打开「陈默」或「林乔」。详情可以编辑、删除。改动只在这台浏览器。右上角「通行大屏」进入通行安防。

**能源监测** `/energy`。点「异常」，应看到「海纳楼客梯回路」。页头说明曲线在大屏。点「能耗大屏」进入能耗监测：水电曲线、楼宇用电、异常表计。

园区、楼宇、房间的按钮叫「空间态势」，企业、合同、公告叫「综合态势」，都会带上当前页作为返回地址。用户、角色、菜单没有业务大屏按钮，顶栏「态势大屏」仍可进入综合态势，返回时回到系统设置页。

筛选没有结果时，表格中间有「清空筛选」和新建。

## 6. 态势大屏收束

从任一跳转进入后，按顶栏顺序点一遍，讲解时每页停几秒即可：

| 场景 | 路径 | 观众应看到 |
| --- | --- | --- |
| 综合态势 | `/overview` | 可点的示意地图、产业环图、出租率、通行与负荷曲线、底部滚动指标 |
| 物业运行 | `/property` | 四个班组进度条、质量雷达、设施在线率 |
| 工单态势 | `/workorders` | 状态环、横向类别条、自动上滚的工单墙 |
| 能耗监测 | `/energy` | 水电双曲线、楼宇用电、异常表计高亮 |
| 通行安防 | `/access` | 人车分时、闸口流量、点位和访客 |
| 告警中心 | `/alerts` | 等级环、来源条、上滚告警墙 |

地图点一栋楼，下方一行字换成这栋楼的状态。顶栏可改园区，六个场景的查询参数保持不变，所以「返回管理端」仍然回到离开前的后台页面。

右上角「演示解锁」可换成周启明或陈予安。Pages 上管理端和大屏同域，解锁后回管理端不必再登录。本地 5173 和 5174 不同源，会话不共享，回管理端要重新点名片。

最后在管理端头像菜单点「退出登录」，应回到登录页。

## 讲的时候可以强调

- 报修能从待受理走到完工，缴费能从逾期登记到缴清。
- 列表上的数字就是筛选器，不是装饰。
- 大屏是驾驶舱，不是第二套工单系统；返回按钮认来源页面。
- 三园和金额、电话都是虚构演示数据。
