# 第一期缺口

这是可点击的中文前端原型，用来走通招商签约和驾驶舱演示。下面这些是故意没做，或做了但边界要说清楚。

## 没有后端

- 没有接口、数据库、账号体系和文件服务。登录只校验三个写死的演示账号。
- 会话在 `localStorage` 键 `park-industry.session`。招商签约在 `park-industry.pipeline.v1`。待办、企业、空间、政策、促进、快报和设置在 `park-industry.ops.v1`。
- 换浏览器、清站点数据，或点「恢复示例」，改动就没了。没有多人同时编辑。
- 三个演示账号看到同一份数据。角色页只是台账，不会按人收起菜单，也不能让苏晚、何安、江衡登录。

## 驾驶舱只读示例

- 本地 `5173` 和 `5174` 不共享 `localStorage`。驾驶舱用内置示例，数字与中台初始样例一致，看不到你刚在中台新建的记录。
- GitHub Pages 上两个应用同域。若浏览器里已经有那两份台账，驾驶舱只读，不会改写。没有台账时仍用同一套示例。
- 投资促进、数据分析、系统设置没有自己的驾驶舱场景。从这些页面点顶栏「驾驶舱」，会打开招商态势。
- 地图是示意，不是测绘，也不能下钻到楼层。

## 页面做到哪

- 中台菜单都有列表、详情和表单，筛空时有空状态。没有审批流、附件、导入导出、消息和打印。
- 数据分析只登记阶段快报的文字和数字。转化率、签约额、空置图在驾驶舱，用 CSS 和 SVG 画，没有图表库的缩放和图例筛选。
- 金额按「亿元 / 万元」文本解析。写成别的单位，驾驶舱就当成没有可加总的数。
- 删除是从本机台账移除，没有回收站。

## GitHub Pages

- 站点地址是 https://dxhcode.github.io/park-industry/ ，中台在 `/admin/` ，驾驶舱在 `/screen/` 。
- 仓库 Settings → Pages 必须手动选：Deploy from a branch，Branch `dist`，目录 `/ (root)`。发布脚本改不了这项。没设之前三个地址都会 404。
- `dist` 分支只放构建产物。执行 `pnpm pages:publish` 会强制覆盖它。
- 深链接刷新靠 `404.html` 把路径交回对应的单页应用。入口页、中台、驾驶舱不要混用路径。
