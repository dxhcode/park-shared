# 演示脚本

产业运营平台第一期前端原型。没有后端，电话和金额都是虚构的。建议按下面的顺序点，大约八分钟。

演示前如果这台浏览器改过数据，先登录，再点顶栏「恢复示例」。本地两个端口不共享浏览器存储，驾驶舱会用内置示例；GitHub Pages 上两个应用同域，驾驶舱只读中台台账。

## 1. 从入口进中台

1. 打开 https://dxhcode.github.io/park-industry/ 。
2. 左边金色卡片是运营中台，右边青色卡片是产业驾驶舱。先点「进入中台」。
3. 落到 https://dxhcode.github.io/park-industry/admin/login 。
4. 点「陈启明」，再点「进入运营中台」。

应当看到墨色顶栏和侧栏，工作台四张数字：待跟进线索、在谈项目、待进行拜访、未完成待办。下面一排圆角入口里有线索、项目库、拜访、合同、履约。

## 2. 招商签约主线

样例主线是星澜智造：线索已经进项目，补充协议待签署，履约节点即将到期。

1. 工作台待办里点「收回星澜补充协议法务意见」。
   地址：`/workbench/tasks/task-xinglan`
2. 点「打开关联」，进入项目「星澜智造二期扩产」。
   地址：`/investment/projects/proj-xinglan-ii`
3. 详情里能看到关联线索、拜访和合同。点合同「星澜智造二期补充协议」。
   地址：`/signing/contracts/con-xinglan`
4. 合同状态是「待签署」。点履约节点「补充协议签署」。
   地址：`/signing/performance/pf-xinglan-sign`
5. 节点上可以再点回合同和项目。

侧栏也可以直接走：产业招商 → 项目库 / 线索 / 拜访，签约管理 → 合同 / 履约。列表里的名称、关联项目、关联合同都能点进详情。

另一条还没建项的线索：

1. 打开 `/investment/leads/lead-beidou`（北渚机器人，跟进中）。
2. 点「转化为项目」。表单会带出企业、园区、联系人和电话，阶段是「线索」。
3. 演示到这里可以点「取消」，不必保存。保存会写进这台浏览器。

筛到没有结果时，列表给出「清空筛选」，不是一块空白表格。

## 4. 产业驾驶舱

中台顶栏「驾驶舱」会按当前菜单打开对应场景，并记住返回位置。工作台、招商、签约页面上也有入口。

驾驶舱首页：https://dxhcode.github.io/park-industry/screen/situation

1. 顶栏有滚动指标，左侧六张场景。
2. 招商态势：示意地图、项目阶段、来源城市、项目名单。点地图上的「临港智造」，标题范围收成这一园；再点一次回到三园合计。
3. 签约看板 `/signing`：已生效及履行大约 4.3 亿元，来自海弈 3.2 亿元和远能 1.1 亿元。
4. 企业分布 `/enterprises`、空间利用 `/space`、政策兑现 `/policy` 各看一眼名单。
5. 告警中心 `/alerts`：第一条紧急事项是远能「主要设备进场」，已经逾期。
6. 点这条告警，回到中台 `/signing/performance/pf-yuan-equip`。名单上的项目、合同、企业、空间、政策同样能点回中台。未登录会先到登录页，登录后回到该页。
7. 驾驶舱右上角「返回中台」回到跳转前的中台页面。

## 5. 收尾

- 顶栏「恢复示例」把招商签约和其余子系统一起盖回初始样例，登录保留。
- 「退出登录」回到登录页。未登录时刷新中台深链接，也会先到登录页。
