# 第 1 部分 01 产业运营大平台（park-industry）

## 1.1 定位与 DEMO 目标

**定位【原】**：面向科技创新产业运营商的科创产业投资与运营基础设施，主线是"投得准、招得好、运营得活、转化得快、退得出"。原文 8 大平台：科创投资决策（TZ）、科创招商（ZS）、科创运营（YY）、科创资产增值（ZC）、科创数据服务（SJ）、科创产业物联网（GY）、科创监测（SC）、科创服务门户（MH）。

**DEMO 要讲清的三件事**：
1. **招得好（P0）**：从产业链图谱和企业公海里找到目标企业 → 评分 → 线索 → 拜访 → 项目 → 合同审批 → 履约 → 落地。主线企业是星澜智造（二期扩产），支线是北渚机器人（线索转项目）。【原】+【对标B7、B8】
2. **投得准（P0，轻量）**：一页投资测算（输入成本、收益、周期，前端算出 IRR、NPV、回收期），加一屏投资回报看板。【原 TZ-01、TZ-04】
3. **闭环可见（P0）**：驾驶舱告警点回中台记录（原型已有），企业档案能跳到 campus 和 gov 看同一家企业（跨平台，见第 4 部分）。

"运营得活、转化得快、退得出"在 DEMO 中各给一页代表性页面（P1），物联网与监测（GY、SC）为 P2。

## 2.1 定位与 DEMO 目标

**定位【原】**：面向园区运营公司的园区内部管理与运营基础设施，主线是"管好人、管好物、管好钱、服务好、处置快"。原文 10 大平台：园区运营管理（YY）、企业服务（QY）、生活服务（SH）、物业管理（WY）、智慧安防（AF）、事件处置（SJ）、智慧消防（XF）、智慧能源（NY）、智慧通行（TX）、决策分析（JC）。

# 第 3 部分 03 政府管理大平台（park-gov）

## 3.1 定位与 DEMO 目标

**定位【原】**：面向政府/管委会的统一数字监管与科技创新管理基础设施，"科技创新管理为核心、政务党建为保障、安全环保监管为底线、数据底座为支撑"。原文 3+1+1 架构：管理平台（GL）、服务平台（FW）、智能监管平台（JG）＋ 智能 BI（BI）＋ 专项业务（ZX）。

**【决策】双主线，均为 P0**：
- **主线 A 科技项目全生命周期**：指南 → 申报 → 形式审查与查重 → 专家评审 → 立项公示 → 任务书 → 经费拨付 → 过程（中期、变更、风险预警）→ 验收 → 成果登记 → 项目库。原文 §6.2"科技创新闭环"与 §6.3.5–6.3.7 是需求依据；原型目前**完全没有**。
- **主线 B 企业/空间监管**：企业名录 → 一企一档 → 风险/信用画像 → 承租用房 → 同楼闲置 → 监管大屏。原型**已有**，v0.2 只做增强（亩均评价、补贴审核校验）。

两条主线在**星澜智造**上交汇：星澜既是被监管企业（风险画像"危化品暂存台账缺页"），又是科技项目申报单位（见 4.4）。
