## 二、逐家要点

### B1 飞企互联（起点）
- **产品体系**：底座「智慧园区凌云中台」，由业务、数据、物联、技术四个子中台组成；官网称已服务 100+ 园区、300+ 场景（lingyun.html）。上层按**园区业态**切四条产品线（digital.html、4093.html）：
  | 产品 | 面向 | 官网写到的体系 |
  |---|---|---|
  | 鸿鹄 G+ | 开发区、高新区、经济区、保税区、大型工业园区 | 产业发展、企业服务、建设管理、运营管理协同（另一处表述为"监管运营、企业服务与产业发展"） |
  | 鸿鹄 P+ | 产业地产、科技园、物流园、文创园等 | 智慧物联、运营管理、企业服务、人文社区、产业生态五大体系；集团化多业态集中管控、物业资产精细化运营 |
  | 鸿鹄 E+ | 企业自建园区、龙头企业园区 | 安全、通行、办公、生活 |
  | 鸿鹄 S+ | 孵化器、众创空间、小微园区 | SaaS 轻量部署，"空间运营 + 资源运营" |
- **服务对象**：园区政府、园区运营方、园区企业、园区服务商、园区公众五大主体（4093.html）。
- **智能化（IoT）六场景**：智慧安防、通行、楼宇、能效、办公、生活（intelligence.html）。
- **生态运营**：产业空间服务、企业服务、公众服务、商家服务（ecology.html）。
- **案例里的亮点**（digital.html）：上海金桥做"产业一张图、经济一张图、资源一张图、园区一张图"；深圳龙岗产服集团做"产业空间服务平台"，汇聚全区国有产业用房租赁信息；珠海高新区平台用于加强"管委会、园企、园区公众"多方沟通。
- **对本项目的意义**：飞企按业态切产品，本项目按主体切三平台，两者能对上：G+ ≈ 政府端（park-gov），P+ ≈ 运营/产业端（park-campus + park-industry）。"四个一张图"可以直接借用为大屏的叙事框架。

### B2 / B2b 华为云智慧园区、华为 IOC 2.0
- **五大场景**（B2）：综合安防、便捷通行、设施管理、智慧能效、物业管理。
- **功能描述**（B2）：视频、闸机、消防多系统集成，"安消一体化"；统一员工 ID，访客全程自助通行；设施预集成 147 家伙伴的 500 种设备，150+ 物模型，100+ 故障诊断规则；物业"服务工单一键触达，并指定责任人……全流程跟踪"；预置 50+ 小程序组件和表单引擎。
- **IOC 2.0**（B2b，二手）：综合态势、综合安防、便捷通行、能效管理、设施管理、环境空间、资产管理、办公会议、网络体验九大板块，基于 3DGIS/BIM/IoT 数字孪生，"一块屏"调度全园。
- **对本项目的意义**：园区运营端的核心卖点是"多系统统一接入 + 告警联动 + 工单闭环"。这对应 02 文档的「事件处置平台」，原型目前恰好缺"告警转工单"。

### B3 中软国际云智慧园区
- **15 项功能**：园区综合态势、安防管理、入侵管理、告警管理、工单管理、人员管理、考勤管理、车辆管理、设施管理、空间管理、环境管理、会议室管理、能耗管理、IOC 基础组件、移动办公。
- **值得演示的闭环**：告警联动实时视频、抓拍、录像、位置和附近安保资源 → 确认后下发到移动端 → 工单可关联事件照片和视频，处理人上传过程照片和视频 → 工单档案可查。入侵检测会联动附近摄像头并显示入侵路线。多级 IOC 架构。
- **对本项目的意义**：可以照搬"告警 → 确认 → 派单 → 现场回传 → 归档"的时间轴作为 02 的 P0 演示。

### B4 腾讯云 微瓴同业开放平台
- **定位**：面向集成商的 PaaS，包括设备接入、CAD/BIM 在线三维建模、零代码"逻辑编排"（如"访客到访会议室联动""执行管控预案"）、数据编排。
- **9 个 IOC 模板**：首页、告警、能源、门禁、停车、安防、消防、照明、电梯，可一键套用后二次编辑。
- **应用场景**中列有：资产经营、资产管理、产业服务、产业绩效、招商引资、投资管理。招商引资场景写的是"支持项目投资、收入计划配置，对标实际与计划投资或收入……针对项目资金计划偏差进行预警"。
- **对本项目的意义**：①大屏场景划分可以参考这 9 个模板；②"计划 vs 实际 + 偏差预警"可以落到 01 的投资决策看板（TZ-04）。

### B5 招商蛇口 InPark / CMInPark
- **InPark**（B5，人民论坛调研）：APP、小程序、管理后台一体，"涵盖物业、产业、政务、生活、办公等 130 多种服务场景"；智慧 BI 和计划管控提炼运营指标；**地块、项目、楼栋、楼层、房间、工位六级空间**管理；BIM+3D 虚拟园区，把产业、空间、企业、人才、服务资源、物联网数据可视化。
- **CMInPark**（B5，转载）："服务 + 管理一体化"，覆盖资产运营、客服体验、园区治理；线上服务 5000+ 园区企业的 33 万员工。
- **资产退出**：首批公募 REITs"蛇口产园 REIT"，打通"投、融、建、管、退"全价值链（B5 人民论坛）。
- **对本项目的意义**：①空间主数据建议采用六级结构；②01 的"退得出"可以用 REITs 作为退出路径示例（有真实先例）；③"服务场景数"适合作为 KPI 展示。

### B6 联东U谷
- **大数据招商**：自建"企业公海"，按区域、产业、营收、税收、经营年限、企业家年龄等维度分析企业扩产动机和能力，配合地面招商顾问；引入企业须过"三审机制"（新闻未写明三审内容）。
- **智慧园区模块**（2021 年新闻）：智慧金融、智慧招聘、智慧政策申报、智慧集采、智慧停车、智慧餐厅、智慧梯控、智慧消防、智慧缴费等十几个模块；"U谷金融服务平台"对接 40 多家金融机构。
- **数据价值**：采集入园企业用电、用水、车货等数据，帮政府分析企业经营状况、帮企业和银行对接。
- **对本项目的意义**：①01 的目标企业库可以叫"企业公海"，筛选维度有现成参考；②"园区运营数据 → 政府经济分析 / 金融授信"可以作为三端联动的一个讲点。

### B7 《慧云智慧园区运营服务平台》使用指南
- **架构**：园区大脑（招商、运营、企业、服务、产业、物联、经济运行、园区概况、智慧党建等多张"一张图"）＋ 运营管理（智慧招商、智慧运营、智慧物业、协同办公、重大项目）＋ 营商环境（企业服务、公众服务、办事直通）＋ 产业服务（区域经济、园区产业、企业成长分析）＋ 智慧物联（安防、消防、环境、能源）＋ 智慧党建。
- **招商闭环"引、研、跟、审、落"**：招商集聚（招商大数据库）→ 商机研判（企业多维视图）→ 需求跟进（按意向程度打标签）→ 需求评审（线上项目评审）→ 项目落地（在线签约、房源分配）→ 招商分析（入驻转化）。招商模块还有园区门户、招商计划、招商任务、招商 CRM、渠道管理。
- **政策服务闭环**：政策发布（解读、截止时间、所需附件）→ 精准推送 → 企业申报 → 专家审核 → 申报公示 → 申报分析（通知数、申报数、通过率）。
- **企业画像与测评**：一企一档；**亩均效益评价**（亩均增加值、亩均税收、全员劳动生产率、单位能耗增加值、单位碳排放增加值、研发费用投入）分 A 优先发展、B 鼓励提升、C 倒逼转型、D 淘汰落后四类；配合"六个一批"（倒逼转型、腾退收购、新建招引、集聚发展、零地技改、配套完善）。
- **重大项目**：项目中心、项目管理、进度、质量、成本监督。
- **对本项目的意义**：①"引研跟审落"可以直接作为 01 的招商主线；②政策申报闭环可以给 02 / 03 共用；③亩均 ABCD 是 03 政府端企业监管很好讲的亮点。

### B8 五度易链 智慧招商
- "定方向 → 选对象 → 管过程"三段：产业链图谱（标识**缺失环节与高价值节点**）、区域产业分析；上百个维度组合筛选；企业 360° 画像，**实力、潜力、适配度综合评分**；企业关系图谱。
- 五大靶向招商：产业链、供应链、资本、榜单、区域。
- 招商管理：**线索接洽 → 签约 → 筹建 → 在建 → 落地投产**全周期，支持卡点问题预警。
- **对本项目的意义**：01 原文的招商闭环停在"签约"。补上"筹建/在建/投产"后，可以和原型已有的"履约节点"接起来。

### B9 园域 AI 招商平台
- AI 绘制产业链图谱并标注企业；AI 推荐目标企业，并给出触达路径；实时抓取企业扩产、投资、搬迁、融资、新品布局等公开信息，生成"高价值招商线索"并预警；AI 生成企业/项目尽调报告。
- **对本项目的意义**：可以作为 P2 的"AI 线索/尽调"占位，演示时只展示一份静态尽调报告即可。

### B10 Colloa 科技管理信息系统 / 专项资金申报管理系统
- **科技管理信息系统**：技术规划与制度、科技组织管理（含专家人才）、项目申报和立项（通知公告 → 一键申报 → 评审 → 项目看板）、科技经费管理（预算模板、执行自动归集并预警、财务集成）、研发过程（中期检查、项目变更、甘特图）、创新成果管理、科技成果转化、学术活动、**项目验收和结题**（到期前自动预警；系统自动采集项目关键信息、关联成果和经费明细；专家复核后归档）、绩效评价。
- **专项资金申报管理系统**：单位注册 → 项目申报（自动生成规范申报书）→ **AI 辅助审查**（自动分类转职能部门）→ 专家评审（专家库，**随机或组合抽取**）→ 实地考察与公示 → 签合同后**按约拨付** → 中期考察（节点自动提醒）→ 结项（备案或尾款划拨）→ 绩效评价、归档。另有**内容查重**、申报标准和时间限制、流程表单动态配置；全程留痕，纪检可按授权回溯。
- **对本项目的意义**：这是 03「科技项目全流程」最直接的产品参照。

### B11 湖北省科技计划项目管理办法及两份规程（业务规则依据）
写入 v0.2 的规则要点（均出自原文条款）：
- 流程：发布申报通知 → 单位申报（须签**科研诚信承诺书**）→ 推荐单位审核推荐 → 形式审查 / 评审（同一方向 ≥3 个参评项目时用"项目评审"，否则用"项目论证"）→ 提出立项建议并**公示 ≥5 个工作日** → 下达立项文件 → **30 天内签订任务书** → 实施（重大事项调整须审批，一般事项可自主调整后备案；可做里程碑式管理）→ 验收 → 验收结论公示 ≥5 个工作日 → 成果登记 → 绩效评价。
- 限项与查重：负责人同一年度只能申报 1 项；有在研未验收项目的不得申报；"严禁通过变换项目名称、项目负责人等方式重复申报"。
- 专家：从专家库随机抽取，遵循"匹配、回避、交叉"；列明回避情形（如被评项目成员、同批次申报人、存在利益关系等）；每位专家每年参评一般不超过 3 次；评审当天公布专家名单。
- 验收：在执行期满前 6 个月至期满后 6 个月内申请；延期最多 1 次，不超过 1 年；专家一般不少于 3 人；70 分及以上为"通过"；不通过可在 3 个月内复议一次。
- 过程检查：实施周期 3 年以内的项目一般不做过程检查，确有必要时用"双随机、一公开"抽查。
- 信用：科研信用"红黑名单"；严重失信"一票否决"。
- **对本项目的意义**：原需求文档没有地域，演示规则可参考这一份。把这些数字写进 mock，状态机就有依据（公示倒计时、任务书 30 天倒计时、验收窗口提示）。

### B12 张江科学城专项发展资金申报（二手转载）
- 申报前置条件：注册地在范围内，且已完成上一年《企业统计年报》。
- 审核时通过公共信用信息服务平台查询，近三年有重大失信的不予审核。
- 支持名单公示；资金拨付前迁出的，不再拨付。
- **对本项目的意义**：03 补贴/资金审核可以演示"自动校验：统计年报已报送 ✔ / 信用无严重失信 ✔ / 注册地在园 ✔"三项。

## 四、结论与可借鉴点

1. **三平台的切分方式站得住。** 飞企按业态把产品分为 G+（开发区/政府）和 P+（产业园运营）；招商蛇口、联东也把"产业服务/投资"和"物业运营"放在一起讲。本项目分出 industry 和 campus 两端，所以要靠**统一企业/空间主数据和跳转**把两端讲成一个运营商的故事（v0.2 跨平台章节）。
2. **园区运营端的标配是"一屏统管 + 告警联动 + 工单闭环"**（B2/B3/B4/B7 都有）。原型已有工单状态机，但工单不接告警。把"告警 → 联动视频 → 转工单 → 移动端回传 → 归档"做成 P0，性价比最高。
3. **招商端的共识是"图谱定方向 → 企业库选对象 → 全周期管过程"**（B7 引研跟审落、B8 定方向-选对象-管过程、B6 企业公海）。和原文相比，多出来的环节是：①**招商项目评审**（B6 三审、B7 需求评审）；②**签约后的落地跟踪：筹建 → 在建 → 投产**（B8）。原型已有"履约节点"，补上这两步成本很低。
4. **空间主数据建议用六级**（地块 → 项目/园区 → 楼栋 → 楼层 → 房间 → 工位，B5）。三端的空间口径冲突（原文附录"口径冲突"一节）可以靠它统一。
5. **政府端科技项目管理可以对照公开规则来做。** B10 给了产品形态，B11 给了可量化的规则（公示 ≥5 个工作日、任务书 30 天、验收窗口 ±6 个月、≥3 名专家、≥70 分通过、负责人限项、回避情形）。原文 03 只在规则 §6.3.5 / §6.2 里提到"评审、立项、任务书"，没有对应模块。v0.2 已补模块（JG-01-07 至 JG-01-11）。
6. **政府端企业监管的讲点**：亩均效益 ABCD 分类（B7）、"四个一张图"（B1 金桥）、补贴审核的自动校验（B12：统计年报、信用、注册地）。这三项都能用 mock 演示，不需要真实对接。
7. **AI 能力**（B9 AI 尽调、B10 AI 辅审）在竞品宣传里已经常见。演示时用"静态生成结果"占位（P2），不做真模型。
8. **数字类卖点**（节能 15%、效率提升 X%）都是厂商自述。演示里不要引用为事实，只能作为"目标值"示意。
