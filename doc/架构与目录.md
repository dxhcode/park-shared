# 架构与目录结构

[返回总目录](./README.md)

四个仓库各自是独立的 Git 仓库和 pnpm workspace，技术上都是 Vue 3 前端。共享库提供主题、组件和模拟数据。三个平台各自实现管理端和大屏。

共享库、产业平台和政府平台的样例园区是滨江云栖科创园、临港智造产业园、光谷生命科学园。运营平台的管理端示例写的是临港智慧园区，态势大屏可以在这三座园之间切换。见 [campus README](./campus/README.md)。

收集本文时，三个平台各自的 `package.json` 声明了 Vue、ant-design-vue、Pinia 和 Vue Router，运营大屏另外声明了 ECharts。`@park/theme`、`@park/components`、`@park/mock` 是 park-shared 的包名。接入示例写在 [共享库 README](./shared/README.md) 的「兄弟仓库怎么引用」：同级目录用 `file:`，或用 pnpm 的 `github:...#main&path:` 只装一个子目录。park-campus 的 `@park/shared` 是该仓库 `packages/shared` 里的工作区包，由其中的 `admin-app` 和 `screen-app` 以 `workspace:*` 引用。

## 技术栈

版本取自各仓库 `package.json` 声明的范围。包管理器都是 `pnpm@10.33.3`。

| 仓库 | Node | 界面 | 状态与路由 | 构建 |
| --- | --- | --- | --- | --- |
| park-shared | `>=20` | Vue `^3.5.13`、ant-design-vue `^4.2.6` | 预览页内切换，无 Vue Router | Vite `^6.3.5` 库模式与 `tsc` |
| park-campus | `>=20` | Vue `^3.5.13`、ant-design-vue `^4.2.6`；大屏另有 ECharts `^6.1.0` | Pinia `^3.0.3`、Vue Router `^4.5.0` | Vite `^6.2.4` |
| park-industry | `>=22.12.0` | Vue `^3.5.43`、ant-design-vue `^4.2.6`、dayjs `^1.11.18` | Pinia `^4.0.3`、Vue Router `^5.3.1` | Vite `^8.3.1` |
| park-gov | `>=20` | Vue `^3.5.22`、ant-design-vue `^4.2.6` | Pinia `^3.0.3`、Vue Router `^4.6.3` | Vite `^7.1.7` |

产业和政府的大屏图表在页面内用 SVG 与 CSS 绘制，这两个应用的 `package.json` 没有 ECharts。共享库的 `ScreenChart` 也是 SVG；`screenLineOption` 等函数返回给 `setOption` 用的普通对象，本仓库不安装 ECharts。见 [共享库 README](./shared/README.md) 与 [政府缺口说明](./gov/GAPS.md)。

## park-shared

仓库根目录：

```text
park-shared/
  packages/theme/        @park/theme
  packages/components/   @park/components
  packages/mock/         @park/mock
  playground/            @park/playground，本地对照页
  scripts/smoke.mjs      导出、主题色、查询与讲解路线检查
  package.json
  pnpm-workspace.yaml    packages/* 与 playground
  README.md  DEMO.md  GAPS.md
```

`pnpm-workspace.yaml` 包含 `packages/*` 和 `playground`。根脚本 `pnpm build`、`pnpm typecheck` 的过滤器是 `./packages/*`，预览应用不参与这两条命令。

### `@park/theme`

CSS 变量、ant-design-vue 4 的 `ThemeConfig`、动效和表面工具类，以及大屏图表 option。

```text
packages/theme/src/
  index.ts       对外导出
  tokens.ts      admin / screen 令牌
  theme.css      CSS 变量
  antd.ts        adminAntdTheme、screenAntdTheme
  apply.ts       applyParkTheme
  motion.css     动效类
  motion.ts
  surface.css    玻璃、墨色、骨架类
  surface.ts
  chart.ts       screenLineOption、screenBarOption、screenPieOption
```

`package.json` 的 `exports` 指向编译后的 `dist/index.js`，样式仍从 `src/theme.css`、`src/motion.css`、`src/surface.css` 导出。`peerDependencies` 是 `ant-design-vue`。构建脚本是 `tsc`。

### `@park/components`

Vue 单文件组件。`peerDependencies` 是 `vue` 和 `ant-design-vue`。Vite 以库模式打成 ESM，样式汇总为 `dist/style.css`。入口 [`packages/components/src/index.ts`](../packages/components/src/index.ts) 导出：

| 组件 | 文件 |
| --- | --- |
| `AppLogo` `PageHeader` `GlassCard` `EmptyState` `KpiStat` | 同名 `.vue` |
| `LoginForm` `LoginPage` `AdminLayout` `ScreenLayout` | 登录与布局壳 |
| `ListPageShell` `DetailPageShell` `DetailSection` `FormPageShell` | 页面壳 |
| `RouteMotion` `ListMotion` | 动效 |
| `KpiTicker` `ScreenKpi` `ChartPanel` `ScreenChart` `MapPanel` | 大屏积木 |

### `@park/mock`

园区、企业、楼宇、公告、工单、来访、看板曲线、演示深链和本地登录会话。入口 [`packages/mock/src/index.ts`](../packages/mock/src/index.ts)。

```text
packages/mock/src/
  data.ts             parks、enterprises、buildings
  fixtures.ts         notices、workOrders、visits
  fixtures-query.ts   这三组列表的查询
  query.ts            企业、楼宇、园区概览
  dashboard.ts        指标、跑马灯、曲线、示意地图
  auth.ts             demoCredentials、login、会话
  link.ts             地址栏 query 与 hash
  story.ts            demoBeats、demoStory、demoPlatforms
  helpers.ts          分页、搜索、mockQuery
  types.ts
```

### `playground`

[`playground/package.json`](../playground/package.json) 用 `workspace:*` 引用上面三个包。Vite 把这三个包的别名指到源码，见 [`playground/vite.config.ts`](../playground/vite.config.ts)。开发服务器端口 `5173`。

```text
playground/src/
  main.ts
  App.vue          在登录、组件对照、页面壳、大屏之间切换
  AuthDemo.vue
  GalleryDemo.vue
  ShellDemo.vue
  ScreenDemo.vue
  preview.css
```

## park-campus

运营平台。工作区包含 `apps/*` 和 `packages/*`。

```text
park-campus/
  apps/admin-app/          @park/admin-app，管理控制台
  apps/screen-app/         @park/screen-app，态势大屏
  packages/shared/         @park/shared，两端共用的站点名、登录、跳转和色板
  pages/index.html         Pages 入口
  pages/404.html           深链刷新回退
  scripts/pages-build.mjs  汇总静态产物到仓库根 dist/
  package.json
  README.md  DEMO.md  GAPS.md
```

`@park/shared` 没有单独的构建脚本，`exports` 直接指向 `src/index.ts`。两个应用依赖它。源码：

```text
packages/shared/src/
  index.ts     site、再导出下面模块
  auth.ts      演示账号与 park-campus-session
  hops.ts      三园切换、管理端与大屏互跳地址
  palette.ts   色板与图表序列
  time.ts      上海时区的当前时间
```

管理端 `src` 按职责分成路由、菜单、布局、Pinia store 和页面。报修在 `views/workorders/`，缴费在 `views/billing/`，其余台账共用 `views/catalog/` 与 `catalog/`。数据初始样例在 `data/`，改动经过 `stores/` 写到浏览器本地。

```text
apps/admin-app/src/
  main.ts  App.vue  menus.ts  theme.ts
  router/  layouts/  stores/  styles/  utils/
  catalog/          台账资源定义
  data/             工单、账单样例
  components/
  views/LoginPage.vue
  views/DashboardPage.vue
  views/workorders/
  views/billing/
  views/catalog/
```

大屏场景在 `views/scenes/`：综合态势、物业运行、工单态势、能耗监测、通行安防、告警中心。图表组件是 `components/EChart.vue`，依赖应用自己的 `echarts`。

```text
apps/screen-app/src/
  main.ts  App.vue  scenes.ts  charts.ts  theme.ts
  router/  layouts/  stores/  data/  composables/
  components/       CountUp、EChart、GlassPanel、KpiTicker、ParkMap
  views/ScenePage.vue
  views/scenes/     Overview、Property、Workorder、Energy、Access、Alert
```

开发时 Vite `base` 为 `/`，管理端端口 `5173`，大屏端口 `5174`。生产构建的 `base` 分别是 `/park-campus/admin/` 与 `/park-campus/screen/`。见两个应用的 `vite.config.ts`。

## park-industry

产业平台。工作区只有 `apps/*`，没有 `packages/`。管理端包名 `admin-app`，大屏包名 `screen-app`。登录、招商签约台账和其余子系统都在管理端源码内；大屏有自己的 `mock/`，同域时只读管理端写下的两份 `localStorage`。

```text
park-industry/
  apps/admin-app/
  apps/screen-app/
  pages/index.html         Pages 入口
  scripts/pages-build.mjs
  scripts/pages-publish.mjs
  package.json
  README.md  DEMO.md  GAPS.md
```

管理端：

```text
apps/admin-app/src/
  auth/accounts.ts         三个演示账号
  mock/                    样例、类型、选项
  stores/                  auth、pipeline、ops
  nav/  router/  layouts/  theme/  config/
  views/login/
  views/workbench/
  views/investment/        项目、线索、拜访
  views/signing/           合同、履约
  views/enterprises/
  views/space/
  views/policy/
  views/promotion/
  views/analytics/
  views/settings/
```

会话键 `park-industry.session`。招商签约台账键 `park-industry.pipeline.v1`。待办、企业、空间、政策、促进、快报和设置键 `park-industry.ops.v1`。

大屏：

```text
apps/screen-app/src/
  mock/          驾驶舱样例；ledger.ts 只读上述两份台账
  nav/  router/  layouts/  stores/  config/
  views/         招商态势、签约、企业、空间、政策、告警
```

Vite `base` 在开发和生产都是 `/park-industry/admin/`、`/park-industry/screen/`。端口仍是 `5173` 与 `5174`。开发服务器把 `/` 重定向到对应 base。

## park-gov

政府平台。工作区只有 `apps/*`。入口页模板在 `scripts/pages-portal.html`，由构建脚本写入 `dist/index.html`，仓库里没有 `pages/` 目录。

```text
park-gov/
  apps/admin-app/
  apps/screen-app/
  scripts/pages-build.mjs
  scripts/pages-portal.html
  scripts/pages-preview.mjs
  scripts/pages-publish.mjs
  package.json
  README.md  DEMO.md  GAPS.md
```

管理端把企业、用房、闲置放在 `stores/registry.ts`（键 `park-gov.registry.v1`），其余台账放在 `stores/affairs.ts`（键 `park-gov.affairs.v1`）。会话在 `auth/accounts.ts`，键 `park-gov.session`。

```text
apps/admin-app/src/
  auth/accounts.ts
  mock/  ledger/  stores/  router/  layouts/  config/
  views/enterprise/    企业名录、风险画像
  views/space/         用地、用房、闲置
  views/ledger/        考核、政策、投诉、报送、统计、设置等共用台账页
```

大屏场景在 `views/scenes/`，样例在 `src/mock/dashboard.ts`。README 与缺口说明写明：大屏数字与管理端样例对齐，运行时不读 `park-gov.registry.v1` 和 `park-gov.affairs.v1`。

```text
apps/screen-app/src/
  mock/dashboard.ts
  router/  layouts/  stores/  config/  utils/
  views/scenes/      监管总览、空间、企业风险、考核、投诉热力、告警
```

Vite `base` 在开发和生产都是 `/park-gov/admin/`、`/park-gov/screen/`。端口 `5173` 与 `5174`。

## 数据落在哪里

| 仓库 | 登录会话 | 业务数据 |
| --- | --- | --- |
| park-shared | `park-auth-session`；记住的用户名在 `park-auth-remember` | 模块内常量，查询不写回 |
| park-campus | `park-campus-session` | 工单 `park-campus-workorders-v1`，账单 `park-campus-bills-v1`，其余台账为 `park-campus-*-v1`（见 `apps/admin-app/src/catalog/resources.ts`），当前大屏园区 `park-campus-park`。大屏曲线在 `apps/screen-app/src/data/parks.ts` |
| park-industry | `park-industry.session` | `park-industry.pipeline.v1`、`park-industry.ops.v1` |
| park-gov | `park-gov.session` | `park-gov.registry.v1`、`park-gov.affairs.v1`；大屏快照在 `apps/screen-app/src/mock/dashboard.ts` |

本地开发时管理端和大屏端口不同，`localStorage` 不共享。GitHub Pages 上同一仓库的两个应用同域。产业驾驶舱在同域时只读中台台账；政府大屏读取 `apps/screen-app/src/mock/dashboard.ts`，源码里不访问上述两份台账键。边界写在 [运营缺口](./campus/GAPS.md)、[产业缺口](./industry/GAPS.md) 和 [政府缺口](./gov/GAPS.md)。
