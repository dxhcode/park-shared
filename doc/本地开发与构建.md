# 本地开发与构建

[返回总目录](./README.md)

命令和端口取自各仓库根目录 `package.json`、应用 `package.json` 和 `vite.config.ts`。四个仓库分开克隆、分开安装。包管理器都写着 `pnpm@10.33.3`。

| 仓库 | Node | 安装 |
| --- | --- | --- |
| [park-shared](https://github.com/dxhcode/park-shared) | `>=20` | 仓库根目录 `pnpm install` |
| [park-campus](https://github.com/dxhcode/park-campus) | `>=20` | 同上 |
| [park-industry](https://github.com/dxhcode/park-industry) | `>=22.12.0` | 同上 |
| [park-gov](https://github.com/dxhcode/park-gov) | `>=20` | 同上 |

park-shared 的 [`.npmrc`](../.npmrc) 打开了 `engine-strict`。组件包的 `prepare` 会调用 Vite，因此安装时需要允许 `esbuild` 的构建脚本。根 `package.json` 的 `pnpm.onlyBuiltDependencies` 包含 `esbuild` 和 `core-js`。campus、industry 的同一字段包含 `esbuild`；gov 写在 `pnpm-workspace.yaml` 的 `onlyBuiltDependencies`。

## park-shared

在仓库根目录：

```bash
pnpm install
pnpm build
pnpm typecheck
pnpm smoke
pnpm dev
```

| 脚本 | 实际动作 |
| --- | --- |
| `pnpm build` | `pnpm -r --filter "./packages/*" run build`。主题和 mock 用 `tsc` 产出 `dist`；组件用 Vite 库模式打 ESM，再用 `vue-tsc` 产出声明 |
| `pnpm typecheck` | 对 `packages/*` 做类型检查。根上的 `pnpm lint` 就是这一条 |
| `pnpm smoke` | `node scripts/smoke.mjs`。检查导出、主题色、查询和讲解路线，不启动浏览器 |
| `pnpm dev` | `pnpm --filter @park/playground dev`，即 Vite，`--host 0.0.0.0 --port 5173` |

预览地址是 http://localhost:5173/ 。右上角可切换「登录与布局」「组件对照」「页面壳」「大屏看板」。地址栏可用 `?view=screen&park=park-binjiang`。`playground` 没有 `build` 脚本，也不在根 `pnpm build` 的过滤器里。

组件库消费方若还没装依赖，先在本仓库执行 `pnpm install && pnpm build`，让三个包的 `dist` 存在。引用方式见 [共享库 README](./shared/README.md)。

## park-campus

```bash
pnpm install
pnpm dev
pnpm build
pnpm typecheck
pnpm pages:build
```

`pnpm dev` 并行启动两个应用：

```bash
pnpm --parallel --filter @park/admin-app --filter @park/screen-app dev
```

也可以只开一端：`pnpm --filter @park/admin-app dev`、`pnpm --filter @park/screen-app dev`。

| 应用 | 开发地址 | 端口 | 开发 base | 生产 base |
| --- | --- | --- | --- | --- |
| 管理端 `@park/admin-app` | http://localhost:5173/ | 5173，`strictPort` | `/` | `/park-campus/admin/` |
| 态势大屏 `@park/screen-app` | http://localhost:5174/ | 5174，`strictPort` | `/` | `/park-campus/screen/` |

`base` 随 Vite 命令变化：`command === "build"` 时用项目页路径，开发时用 `/`。见 `apps/admin-app/vite.config.ts` 与 `apps/screen-app/vite.config.ts`。

每个应用的 `build` 是 `vue-tsc --noEmit && vite build`，产物在该应用目录的 `dist/`。根 `pnpm build` 依次构建这两个应用。`pnpm pages:build` 会再构建一次，并汇总到仓库根 `dist/`，步骤见 [Pages 发布流程](./Pages发布.md)。

未登录打开管理端会进入登录页。演示账号见 [总目录](./README.md#park-campus)。

## park-industry

```bash
pnpm install
pnpm dev:admin
pnpm dev:screen
pnpm build
pnpm typecheck
pnpm pages:build
```

两个开发命令分开执行，各占一个终端：

| 应用 | 包名 | 开发地址 | 端口 | base |
| --- | --- | --- | --- | --- |
| 运营中台 | `admin-app` | http://localhost:5173/park-industry/admin/ | 5173 | `/park-industry/admin/` |
| 产业驾驶舱 | `screen-app` | http://localhost:5174/park-industry/screen/ | 5174 | `/park-industry/screen/` |

开发和生产使用同一 `base`。Vite 插件会把访问 `/` 的请求重定向到该 base。

应用 `build` 是 `vue-tsc -b && vite build`。根 `pnpm build` 是 `pnpm -r --if-present build`，会构建工作区里带 `build` 脚本的包，也就是这两个应用，产物分别在 `apps/admin-app/dist` 和 `apps/screen-app/dist`。

`pnpm pages:publish` 会检查工作区是否干净，再构建并强制推送 `dist` 分支。发布前先提交源码。详见 [Pages 发布流程](./Pages发布.md)。

## park-gov

```bash
pnpm install
pnpm dev:admin
pnpm dev:screen
pnpm build
pnpm typecheck
pnpm pages:build
pnpm pages:preview
```

| 应用 | 包名 | 开发地址 | 端口 | base |
| --- | --- | --- | --- | --- |
| 管理端 | `admin-app` | http://localhost:5173/park-gov/admin/ | 5173 | `/park-gov/admin/` |
| 态势大屏 | `screen-app` | http://localhost:5174/park-gov/screen/ | 5174 | `/park-gov/screen/` |

应用 `build` 同样是 `vue-tsc -b && vite build`。根 `pnpm build` 是 `pnpm -r --if-present build`。

按项目页路径在本地看整站：先 `pnpm pages:build`，再 `pnpm pages:preview`。预览服务器默认监听 `0.0.0.0:4173`，前缀 `/park-gov/`，地址 http://127.0.0.1:4173/park-gov/ 。端口可用环境变量 `PORT` 覆盖。脚本在找不到 `dist/index.html` 时直接退出。

`pnpm pages:publish` 在未设置 `PAGES_PUBLISH=1` 时只打印步骤并退出，不推送。见 [Pages 发布流程](./Pages发布.md)。

## 同时开多个仓库

共享库预览、三个平台的管理端都默认占用 `5173`，三个大屏都默认占用 `5174`。campus 的两个端口还设置了 `strictPort: true`，端口被占用时 Vite 会失败而不是改端口。需要对照多个仓库时，分开开，或只启动当前要看的应用。

## 类型检查

| 仓库 | 命令 | 范围 |
| --- | --- | --- |
| park-shared | `pnpm typecheck` | `packages/*`。组件用 `vue-tsc`，主题和 mock 用 `tsc --noEmit` |
| park-campus | `pnpm typecheck` | `@park/admin-app`、`@park/screen-app` 的 `vue-tsc --noEmit` |
| park-industry | `pnpm typecheck` | 工作区里带 `typecheck` 的包，应用脚本是 `vue-tsc -b --pretty false` |
| park-gov | `pnpm typecheck` | 同上，应用脚本是 `vue-tsc -b` |

四个仓库的根 `package.json` 都没有 ESLint 或测试脚本。共享库的回归入口是 `pnpm smoke`。
